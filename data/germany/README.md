# Germany data

Canonical geographic data for the German postcode journey.

## Sequence

The journey begins at **01067** and proceeds through every real geographic German postcode in ascending numeric order.

## Postcode record

Each postcode record can contain:

- postcode
- city
- optional district/Stadtteil
- Landkreis or Kreisfreie Stadt
- Bundesland
- representative place
- representative coordinates
- legally routable access coordinates
- facts
- optional legally reusable image metadata

Community content is deliberately not part of this canonical dataset in version 1.
