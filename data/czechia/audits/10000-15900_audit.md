## 2. Průběžná technická kontrola

### I-01 — strukturální podkontroly — ČÁSTEČNĚ DOLOŽENO
Read-only SQL kontroly nad 33 řádky a 212 fakty (2026-11-16):
- 33/33 záznamů má očekávaná kořenová pole včetně `verification`, `representative_point`, `access_point`, `facts`, `sources` a `translations`.
- 33/33 má sedm jazyků; 0 zjištěných rozdílů v pořadí/seznamu ID mezi jazykovými verzemi.
- 212/212 faktů má neprázdné `sources`; žádná z kontrolovaných faktových polí `sources` není prázdná.
- 49/212 faktů nemá `map_category`. Jde o potvrzený rozpor s povinným polem ve schema a Content Standardu; přesný seznam je uveden v nálezu I-01-MAP-01 níže.
- 1/212 faktů nemá explicitní vlastnost `location`: 10900 / fact_004 „Pod Vartou: pravěké sídliště pod dnešní zástavbou“. Auditní prompt F vyžaduje explicitní objekt nebo explicitní `null`; schema pole ponechává volitelné. Jde proto o nález k vyjasnění podle auditního promptu, nikoli o automatickou chybu JSON Schema.
- V této podkontrole nebyla provedena plná validace každého objektu proti JSON Schema, kontrola funkčnosti všech URL, faktická rešerše ani kontrola všech poloh. I-01 proto zůstává otevřena.

### I-01-MAP-01 — chybějící povinná mapová klasifikace
- **Závažnost:** HIGH.
- **Rozsah:** 49 faktů v PSČ 10000–10900.
- **Problém:** chybí `facts[].map_category`, přestože schema vyžaduje právě jednu hodnotu z enumu 17 kategorií a Content Standard 11A stanoví povinnost.
- **Dotčená PSČ:** 10000 (4), 10100 (3), 10200 (2), 10300 (6), 10400 (10), 10600 (5), 10700 (4), 10800 (9), 10900 (6).
- **Důkaz:** read-only SQL kontrola 2026-11-16 nad 212 fakty; nulový počet neplatných neprázdných hodnot, ale 49 chybějících hodnot.
- **Požadovaná oprava:** v samostatné autorizované opravné fázi určit mapovou kategorii každého z těchto 49 faktů podle hlavního tématu, nikoli pouze podle fyzického typu polohy; následně ověřit celý enum a znovu validovat dotčené záznamy. Během tohoto auditu nic neměnit.

### I-01-LOC-01 — chybějící explicitní location
- **Závažnost:** MEDIUM.
- **PSČ/fakt:** 10900 / fact_004.
- **Problém:** vlastnost `location` v JSON zcela chybí, místo aby obsahovala obhajitelný objekt nebo explicitní `null`.
- **Důkaz:** read-only SQL kontrola 2026-11-16.
- **Požadovaná oprava:** v opravné fázi ověřit, zda lze doložit polohu; uložit objekt nebo explicitní `null` podle standardu. Neměnit obsah faktu.
