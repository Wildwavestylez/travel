# TRAVEL — WORK PROMPT

Přečti si a bezvýhradně dodrž aktuální pravidla projektu:

1. `schema.json`
2. `CONTENT_STANDARD.md`
3. `data/<country>/COUNTRY_PROFILE.md`
4. `data/<country>/sequence.json`

Tyto soubory jsou hlavní zdroj pravdy. Nevymýšlej vlastní pravidla, pole, kategorie, strukturu ani obsahové zkratky.

Pracuj od **PSČ / geografického identifikátoru: <XXX>** a pokračuj podle aktuální `sequence.json`.

Pro každý záznam:

**prozkoumej → zjisti skutečný význam místa → vyber nejlepší příběhy → vytvoř nebo přepracuj záznam podle aktuálního schema → přidej GPS ke konkrétním místům, pokud je fakt na konkrétní místo vázaný → ověř zdroje → přelož → validuj → ulož → pokračuj dál.**

Pokud záznam již existuje, neposuzuj ho jako hotový jen proto, že existuje. Porovnej ho s aktuálním schematem a CONTENT_STANDARD a podle potřeby ho přepracuj.

Pokud neexistuje, vytvoř nový.

**Neměň `schema.json` ani `CONTENT_STANDARD.md`.**

Nevyráběj balast ani umělý počet faktů. Nezastavuj se u první známé turistické zajímavosti. Hledej skutečné historické, kulturní, přírodní, průmyslové, technické, dopravní, osobnostní a hidden-gem příběhy místa.

Po každém úspěšně dokončeném a ověřeném záznamu pokračuj automaticky na další podle sequence.

Na konci běhu stručně uveď:
- zpracované záznamy,
- případné přeskočené,
- případné chyby,
- kde přesně pokračovat příště.
